# 首版发布简报

## 用户与问题

目标用户是中国大陆的程序员求职者。用户需要把真实经历转化为可验证的结构化简历，并针对具体 JD 获得不捏造事实的优化建议。

## 必须成功的用户路径

受邀用户注册并验证邮箱后，可以上传文本型 PDF/DOCX 或粘贴文本；确认提取的事实；粘贴 JD；审核每条修改；导出中文 ATS 友好简历；之后可删除全部数据。

## 首版不做

不接入未获授权招聘平台、不登录用户平台账号、不自动投递、不支持扫描 PDF OCR、不做企业版或付费订阅。

## 项目形态与部署

单仓库、自托管全栈 SaaS：Next.js Web、FastAPI API、Python Worker、PostgreSQL、Docker Compose、Caddy，先部署到一台中国大陆阿里云服务器。

## 数据与风险

简历属于高敏感数据。原始文件解析后立即删除；结构化数据需要用户确认；所有事实性修改均需用户审批。最大风险是虚构事实、越权访问、文件残留、模型成本失控和未授权岗位数据访问。

## 回滚策略

应用按镜像 tag 回退；数据库采用向前修复，破坏性迁移前必须备份。Connector 和 Agent 搜索由 Feature Flag 独立关闭。生产数据库每日备份，最长保留 35 天，并在上线前验证恢复流程。
