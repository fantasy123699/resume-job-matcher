# 秋招岗位公开页面监控

该脚本每天读取经登记的政府、高校或企业官方招聘页面，按关键词筛选公开岗位，生成 Markdown 与 CSV 日报。它不登录招聘平台、不绕过验证码或反爬措施、不自动投递，也不保存完整 JD 镜像。

## 快速开始

在仓库根目录执行：

```powershell
Copy-Item config/job_watch.example.json config/job_watch.local.json
uv sync --project backend --all-groups
uv run --project backend python apps/worker/job_watch.py --config config/job_watch.local.json --dry-run
```

确认输出正常后，去掉 `--dry-run`。日报会写到 `data/job_watch/YYYY-MM-DD.md` 和 `.csv`，`latest.md` 始终指向最近一次运行结果；`cumulative.csv` 和 `history.json` 保存从起始日期以来的累计岗位，`seen.json` 用于兼容已有去重状态。`data/` 已被 Git 忽略。

## 关键词配置

- `include_keywords`：JD 或职位名称应包含的技术、岗位方向关键词。
- `campus_keywords`：用于限定秋招/校招，例如 `2027届`、`校园招聘`、`应届生`。
- `exclude_keywords`：用于过滤社招、外包或不考虑的方向。
- `min_score`：标题命中一个关键词计 3 分，正文命中计 1 分。
- `history_start_date`：首次回填和历史累计的起始日期，例如 `2026-08-01`。
- `max_age_days`：过滤能识别出发布日期且过旧的公告；无法识别日期的岗位保留并标记为“未知”。

关键词匹配不区分英文大小写。当前配置覆盖后端、软件研发、数据开发、算法、云计算、基础架构、嵌入式软件等相近技术方向；可以继续按目标 JD 增删关键词。

- 西安电子科技大学就业信息网：使用官网公开的 2027 关键词搜索结果及历史分页，不调用隐藏接口。

标题已经命中技术关键词并带发布日期的岗位会直接收录。对于“某公司 2027 校园招聘”这类标题，脚本会在每个来源设定的上限内读取公开正文，防止遗漏藏在综合简章里的后端、软件研发和算法岗位。

已经写入 `history.json` 的链接不会重复下载正文；每天只检查公开列表中的新链接并合并进累计报告，避免来源增加后日常任务持续变慢。

## 增加来源

每个来源必须是无需登录即可访问的官方 HTTPS 页面，并登记所有者、来源类型、域名白名单、robots 地址、使用说明和复核日期。脚本只跟随 `allowed_hosts` 内、且符合 `link_url_pattern` 的链接。

对于公开历史分页，可以配置 `pagination_url_template`、`max_listing_pages`、`item_selector` 和 `listing_date_selector`。脚本遇到早于 `history_start_date` 的页面条目后停止继续翻页，之后每天仍会保留以前已经累计的岗位。

只有当列表本身明确是学校的校园招聘/招聘简章栏目时，才可以把来源的 `campus_scope` 标为 `true`。此时岗位不必在标题中重复出现“校招”，但仍需命中技术关键词且不能命中排除词。

新增来源前需要人工确认其服务条款与 robots 规则。动态渲染、需要验证码或禁止自动访问的页面不要接入；牛客、应届生等招聘聚合平台不在默认来源中。某来源条款变化后，将 `enabled` 改为 `false` 即可立即停用。

若站点明确返回 `404/410` 表示没有 `robots.txt`，脚本按“无 robots 指令”处理；超时、TLS 错误和其他状态码都会停用该来源并写入错误报告。

抓取失败会记录在日报的“采集错误”中。单个来源失败不会冒充“今日没有岗位”。

临时补跑单个来源时可使用 `--source 来源ID`，例如 `--source xidian_career`；正常的每天 11 点任务不带此参数，仍会检查全部启用来源。

## Windows 每日运行

先完成一次非 `--dry-run` 的手动运行，然后在 PowerShell 中执行：

```powershell
.\scripts\register_job_watch_task.ps1 -At "11:00"
```

这会创建当前用户的 Windows 每日计划任务。注册脚本不会覆盖同名任务；如需改时间，应在任务计划程序中显式修改，或先手动删除旧任务再注册。

计划任务调用 `scripts/run_job_watch.ps1`，默认读取未提交 Git 的 `config/job_watch.local.json`。
